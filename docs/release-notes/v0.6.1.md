## 1. Executive Summary

Release `v0.6.1` is a targeted security, reliability, and adversarial hardening patch following the `v0.6.0` autonomous repair milestone. It eliminates blind spots identified during adversarial review across Windows filesystem semantics (NTFS directory junctions, reparse points, DOS 8.3 device name suffixes, trailing dot/space normalization), repair patch validation (enclosing declaration boundary verification, overlapping match protection), compiler preflight execution reliability, token accounting precision across fallback models, fail-closed engine error classification, and static panic checking.

## 2. Hardening Fixes & Defenses

### 2.1 Filesystem & Windows Reparse Point Security
- **NTFS Directory Junction & Reparse Point Detection (`replayfix_core::worktree`)**:
  - Implemented `is_symlink_or_reparse_point` on Windows inspecting `FILE_ATTRIBUTE_REPARSE_POINT` (`0x0400`) via `std::os::windows::fs::MetadataExt`.
  - Enforced canonical root containment in `write_file` to prevent symlink and directory junction path traversal attacks trying to mutate files outside the sandbox root.
  - Added native Windows junction test (`cmd /c mklink /J`) verifying junction containment rejection.
- **DOS Device & Trailing Dot/Space Neutralization (`replayfix_core::manifest`)**:
  - Hardened `assert_safe_path` against multi-dot DOS reserved device patterns (e.g., `CON.txt.bak`, `NUL.tar.gz`) by checking the stem prefix prior to any extensions.
  - Stripped and rejected trailing dots and whitespace in individual path segments which Win32 APIs silently normalize, closing potential path-confusion bypasses.

### 2.2 Autonomous Repair & Block Patcher Defenses
- **Enclosing Declaration & Symbol Boundary Verification (`replayfix_core::repair::BlockPatcher`)**:
  - Enhanced `touched_symbols` validation so that declared symbols must either be introduced directly in `replace_block` or belong to the active enclosing declaration scope surrounding `search_block`.
  - Added overlapping match detection to guarantee `search_block` matches uniquely without ambiguous multi-match overlaps.
- **Fail-Closed Fallback Token Accounting (`replayfix_core::repair::TokenAccounting`)**:
  - Corrected multi-model token cost accumulation when fallback activates (e.g., transitioning from `muse-spark-1.3` to `muse-wonder-1.0` or open-weights fallback).
  - Maintains exact integer nano-dollar rate cards across homogeneous and heterogeneous attempts, preventing fractional drift in `total_cost_micros_usd`.
- **Preflight Node 24 ESM Stdin Hardening (`replayfix_core::repair::SyntaxPreflight`)**:
  - Ensured syntax checking cleanly feeds source code into `node --input-type=module --check` across Node 24 versions without premature stdin closure or pipe hang.
- **Dynamic Syntax Preflight State Reflection (`replayfix_core::engine`)**:
  - Ensured `syntax_preflight_passed` in the repair telemetry accurately reflects dynamic preflight results rather than defaulting to static pass values.
  - Converted error checks in `engine.rs` from partial `if let` blocks to exhaustive `match` arms to guarantee fail-closed handling for all security violations.

### 2.3 CLI & Zero-Panic Invariants
- **Reasoning Effort CLI Validation (`replayfix-cli`)**:
  - Added strict command-line argument validation rejecting `--reasoning-effort max` (exit code `2`) at the CLI boundary before invocation reaches the core library.
  - Added integration test `test_cli_rejects_max_reasoning_effort` in `tests/cli.rs`.
- **Compile-Time Zero-Panic Enforcement**:
  - Enforced crate-level `#![cfg_attr(not(test), deny(clippy::unwrap_used, clippy::expect_used, clippy::panic, clippy::todo, clippy::unimplemented, clippy::unreachable))]` in both `replayfix-core` and `replayfix-cli`.
- **Robust Lexical Tokenizer in `check-panics.ps1`**:
  - Replaced crude string pattern matching with a full lexical state-machine scanner that strips comments, string literals, and character constants before checking for unwrap/expect/panic tokens.
  - Added self-test mode (`powershell -File .specify/scripts/check-panics.ps1 -SelfTest`) with adversarial test fixtures.
