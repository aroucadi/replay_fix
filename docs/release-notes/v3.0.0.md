## 🌟 Executive Summary

**ReplayFix v3.0.0** delivers a genuinely repository-agnostic, zero-shot video-to-code debugging and repair pipeline powered by live Meta AI models (`muse-spark-1.3`, `muse-wonder-1.0`, `sam-3.1`) and real Playwright Chromium CDP verification. Given only a raw `.mp4` screen recording of a visual bug and a target Git repository, ReplayFix v3.0.0 automatically discovers the target source file, mounts standalone UI components or full-stack web apps in an isolated scratch sandbox, grounds the visual interaction in the live DOM, reproduces the failure in Gate 1 (RED), synthesizes a surgical AST patch via Meta Muse, verifies stability across two consecutive browser runs in Gate 2 (GREEN), and seals an Ed25519-signed RFC 6962 Merkle audit receipt.

---

## 🚀 Key Highlights & New Capabilities

### 1. Universal Zero-Shot Component Mount Harness (`discovery.rs`)
- **In-Browser Babel Transpilation (`['env', 'flow', 'react']`)**: Automatically transpiles raw ES6, Flow (`// @flow`), and JSX component libraries (such as `react-resizable`) directly in Chromium without requiring pre-built webpack bundles.
- **Static HTML Asset Verification (`html_assets_exist`)**: Detects and skips unbuilt demo templates (e.g., `examples/1.html` referencing missing `bundle.js` files) so component libraries always mount cleanly.
- **Offset-Parent Drag Physics (`SelfContainedDraggableCore`)**: Computes pointer coordinates relative to `node.offsetParent.getBoundingClientRect()` and assigns axis-specific ARIA slider roles/labels (`Resize Handle NW`, `Resize Handle SE`), faithfully reproducing real DOM layout oscillation bugs on unpatched components.

### 2. Multi-Frame Optical-Flow Drag Trajectory & Physical Jitter Oracle (`perception.rs`, `browser.rs`)
- **Frame-Pair Displacement (`RoiDiffer::pair_change`)**: Extracts both initial click coordinates and terminal drag vectors across dense 100ms video frames.
- **Physical Bounding-Box Jitter Telemetry (`DRAG_AND_OBSERVE`)**: Samples `targetLocator.boundingBox()` across 10 drag steps in Chromium, quantifying frame-to-frame acceleration spikes and sign reversals in basis points (`jitter_score_bps`).

### 3. Live Meta AI Wire Protocol & Lexical Scope Patching (`gateway.rs`, `repair.rs`)
- **Responses API Null-Error Handling**: Properly handles `"error": null` on `https://api.meta.ai/v1/responses` and extracts `reasoning_tokens` from `output_tokens_details`.
- **Flow/ES6 Method Scope Resolution (`BlockPatcher`)**: Tracks parenthesis depth (`paren_depth`) and class method declarations (`resizeHandler(...)`) so destructured parameters and Flow return annotations never corrupt lexical symbol verification.
- **24-Hour Prefix Caching**: Achieves >95% cached prompt token hits (`2531 / 2607` tokens cached) across live `muse-spark-1.3` repair turns.

### 4. Execution Authenticity & Forensic Provenance Matrix (`receipt.rs`, `ui.rs`)
- Every CLI run and `audit_receipt.json` now includes a 9-stage `StageExecutionMatrix` (`video_ingestion`, `sam_spatial_grounding`, `interaction_trajectory`, `deliberation_agent_loop`, `code_patch_synthesis`, `gate1_baseline`, `gate2_stability`, `gate3_stress_quorum`, `cryptographic_attestation`) with honest per-stage provenance (`REAL`, `HEURISTIC`, `MOCKED`, `HARDCODED`, `SKIPPED`, `FAILED`, `UNVERIFIED`).
