# ReplayFix v0.1.0 — Walking Skeleton

**Released:** 2026-10-26 · Full details: [CHANGELOG](../../CHANGELOG.md#010---2026-10-26)

- `replayfix doctor` checks Git (2.30+), Node.js (18+), Playwright (1.40+) and FFmpeg (4.4+), prints install advice, and supports `--json`.
- `replayfix repro` accepts flags or `--manifest`, validated against the canonical `task_manifest.schema.json`.
- Path traversal in `--repo`, `--video` and manifest paths is rejected with exit code 11.

**Known limitations:** `repro` validates and hydrates the task only; Gate 1 execution and repository isolation come later.
