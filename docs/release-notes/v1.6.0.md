## The 5 Pillars of Release 1.6

### Pillar 1: Meta Muse Spark 1.3 as Sovereign Agent Loop Brain
- High-throughput (`305 tok/s`) multi-turn deliberation engine managing sequential turns (Grounding ➔ Reproduction ➔ Diagnosis ➔ Verification ➔ Inoculation).
- Structured autonomous tool calling across 4 canonical substrate tools:
  - `replayfix_reproduce`: FFmpeg keyframes + SAM 3.1 snapping + Playwright CDP Gate 1 RED execution.
  - `replayfix_inspect_trace`: Analyzes console, network, and DOM event traces.
  - `replayfix_verify_patch`: Evaluates candidate patches in ephemeral scratch clones ($\Delta\text{repo}=0$).
  - `replayfix_inoculate`: Synthesizes permanent Playwright regression specs (`tests/repro/rf_<id>.spec.ts`).
- Prompt prefix locking with `prompt_cache_key: "replayfix-v1.6-spark-agent-loop"` ensuring rapid, sub-second turn latency.

### Pillar 2: Meta Muse Wonder 1.0 with Encrypted Deliberation Backtracking
- Specialized AST search/replace code repair conforming strictly to `{ explanation, target_file, search_block, replace_block, touched_symbols }`.
- Stateful reasoning graph retention: On retry attempts (following compiler errors or Gate 3 flakiness), the harness threads `previous_response_id` and cached `reasoning.encrypted_content` back to Wonder, eliminating context thrashing.

### Pillar 3: Sub-60s Sovereign End-to-End Macro Pipeline (`replayfix heal`)
- Unified CLI subcommand orchestrating the entire end-to-end lifecycle in `< 60s`.
- Automates: Video Ingestion ➔ FFmpeg Keyframes ➔ SAM 3.1 Contours ➔ Voice Intent Lock ➔ Ephemeral Dev Server (:0) ➔ Spark Multi-Turn Loop ➔ Wonder AST ➔ Gate 2 Stability ➔ Gate 3 Stress Quorum ➔ Permanent Inoculation ➔ RFC 6962 Merkle Receipt.

### Pillar 4: Autonomous Backtracking & Error Self-Correction
- Reactive feedback loops ingesting TypeScript compiler errors and Playwright assertion failures into the next turn context.
- Gate 3 concurrency and latency perturbation flakiness detection, driving Wonder to incorporate reactive event guards or state synchronization.
- Fail-closed quarantine (`triage_report.json`, Exit 21) if attempts fail across 3 attempts or 180s budget.

### Pillar 5: Hardened Offline Proof Portal (`proof_viewer.html`)
