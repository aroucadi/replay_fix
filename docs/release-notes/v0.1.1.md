# ReplayFix v0.1.1 — Security Hardening

**Released:** 2026-10-26 · Full details: [CHANGELOG](../../CHANGELOG.md#011---2026-10-26)

- Rejects UNC paths, Windows reserved device names (in any path segment) and NTFS alternate data streams in repo, video and manifest paths (`SECURITY_VIOLATION`, exit 11).
- Normalizes Windows backslashes so path checks behave the same on Windows, macOS and Linux.
- Validates `port_env_var`, `healthcheck_path` and `startup_timeout_ms` in the environment adapter.
- `doctor` suggests installation commands for your platform (`winget`, `brew`, `apt`/`dnf`).
- Replaced the machine-specific Cargo test runner with native execution plus opt-in signing scripts for Windows Smart App Control.

**Breaking changes:** none for CLI users. `OsFamily::Unix` was split into `MacOS`, `Linux` and `OtherUnix`.

**Known limitations:** `repro` validates a task and stops; gate execution arrives in later releases.
