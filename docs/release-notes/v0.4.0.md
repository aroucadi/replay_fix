# Release Notes — ReplayFix v0.4.0

**Release Date**: 2026-10-27
**Tag**: `v0.4.0`
**Specification**: `specs/040-v0.4-playwright-cdp-grounding`

## Summary

ReplayFix **v0.4.0** delivers **Spec 040 (`040-v0.4-playwright-cdp-grounding`)**: **Playwright CDP spatial-semantic grounding**, **accessibility tree (`ariaSnapshot`) DOM Grounding verification**, **Fail-Closed Ambiguity Guard (`AMBIGUOUS_GROUNDING`, exit code `22`)**, **line-delimited JSON-lines IPC (`PlaywrightBridge`)**, and **live Chromium two-gate verification (`--live-browser` and `--headed`)** inside isolated scratch sandboxes.

While v0.3.x established isolated scratch sandboxes (`ScratchSandbox`), $\Delta \text{repo} = 0$ verification (`WorktreeManifest`), and dynamic ephemeral ports (`EphemeralPort`), its gate oracle inspected source files statically. With **v0.4.0**, ReplayFix serves the isolated scratch workspace over `127.0.0.1:<ephemeral_port>`, launches a real Playwright Chromium instance, reverse-probes interactive targets at `(click_x, click_y)`, enforces the **DOM Grounding Invariant** against `ariaSnapshot`, reproduces the live runtime `TypeError` in **Gate 1 (RED)**, applies the unified diff on disk inside the scratch sandbox, and verifies **Gate 2 (GREEN)** in the live browser under the identical SHA-256 behavioral contract.

## Highlights & New Capabilities

### 1. Spatial-Semantic Locator Grounding & DOM Grounding Invariant (`replayfix_core::locator`)
- **Composite Basis-Point Scoring (`0..=10_000` bps)**: Evaluates DOM candidates discovered via `document.elementFromPoint(x, y)` and ancestor walking across three deterministic signals:
  1. **Spatial Containment (`4000` bps)**: Point `(x, y)` falls strictly inside the element's bounding box `[x, x + width] x [y, y + height]`.
  2. **Semantic Accessibility Identity (`4000` bps)**: Explicit `data-testid` or ARIA role (`button`, `link`, `textbox`, `checkbox`, `menuitem`, `tab`) paired with a non-empty accessible name.
  3. **Hierarchy Specificity (`0..=2000` bps)**: Favoring inner interactive controls over outer layout wrappers (`depth_from_hit <= 4`).
- **DOM Grounding Invariant**: Every candidate locator (`getByRole` / `getByTestId`) is cross-verified against the live Playwright `ariaSnapshot` YAML before execution. Any candidate missing from the accessibility tree is rejected.
- **Strict `.first()` Ban**: Positional disambiguators (`.first()`, `.nth()`, `:nth-match`) are strictly forbidden in `LocatorResolver`.
- **Fail-Closed Ambiguity Guard (`AMBIGUOUS_GROUNDING`, Exit Code `22`)**: When two or more candidates fall within the ambiguity margin ($|\Delta S| < 0.25$, or `< 2_500` bps), ReplayFix abstains immediately and emits `triage_report.json` with `status: "AMBIGUOUS_GROUNDING"` and `exit_code: 22`.

### 2. Ephemeral Loopback HTTP Server & JSON-Lines Playwright Bridge (`replayfix_core::browser`)
- **`SandboxServer`**: Serves the isolated `ScratchSandbox` directory over `127.0.0.1:<ephemeral_port>` with path-traversal, Windows drive-letter prefix, and symlink defenses (`403 Forbidden`), plus deterministic shutdown.
- **`PlaywrightBridge`**: Spawns a lightweight Node.js child process communicating via flushed line-delimited JSON (`\n`) over `stdin`/`stdout` (`START_BROWSER`, `PROBE_PAGE`, `CLICK_AND_OBSERVE`, `SHUTDOWN`), supervised by `ScratchSandbox` and `Platform::terminate_process_tree`.

### 3. Live Browser Two-Gate Verification (`--live-browser` & `--headed`)
- **`replayfix repro --live-browser`**: Runs the full `Init -> Gate1Red -> Repair -> Gate2Green` state machine against live Chromium while preserving `--mock-heal` for ultra-fast offline tests.
- **`--headed` Support**: Launches a visible Chromium window when combined with `--live-browser`.
- **Receipt Schema `"0.4"`**: Bumps `schema_version` to `"0.4"`, sets `substrate: "playwright-cdp"` for live browser runs, and records `grounding_telemetry` (`click_x`, `click_y`, `viewport_width`, `viewport_height`, `resolved_selector`, `candidate_score_bps`, `score_margin_bps`, `aria_snapshot_sha256`, `dom_grounded_verified`).
