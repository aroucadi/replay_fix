# ReplayFix v1.4.0 Release Notes — Agent Experience Revolution

**Release Date**: 2026-11-01  
**Milestone**: Release 1.4.0 (`Spec 140`)  
**Status**: General Availability / Hackathon Standard  
**Theme**: Human-Agent Interaction (HAI), Conversational UX, and Developer Ergonomics

---

## Executive Summary

ReplayFix Release 1.4 represents a major evolution in how software engineers interact with autonomous verification and repair harnesses. While previous releases established mathematical fail-closed authority, live Meta AI multimodal inference (SAM 3.1 & Whisper), and Universal SPA isolation, ReplayFix 1.4 delivers a first-class **Agent Experience (AX)** directly inside the terminal.

Users no longer need to memorize complex CLI flags. Launching `replayfix` in an interactive terminal opens an intuitive, conversational agent shell that understands natural language, presents transparent execution plans, enforces tiered security permissions, renders in-place progress spinners, and provides interactive diff review before any code is modified.

## The 12 UX/AX Pillars: Capabilities Matrix

| Pillar | Implemented Capability in v1.4.0 | Verification Evidence |
| :--- | :--- | :--- |
| **1. Conversational UX** | Natural language intent parser, context continuation, slash shortcuts (`/repro`, `/doctor`, `/sweep`, `/verify`, `/proof`, `/status`, `/resume`, `/exit`). | Unit tested across 20+ query patterns in `crates/replayfix-cli/src/intent.rs`. |
| **2. Agent UX** | Two-stage "Plan-then-Execute" pipeline; structured `ExecutionPlan` cards before consequential action; observable tool calls. | `ExecutionPlan::render_card` displays planned steps, tools, and risks. |
| **3. Permission & Approval** | Three-tier security model (`Low`, `Medium`, `High`) with contextual dialogs (`Allow Once`, `Allow for Session`, `Deny`). | `PermissionManager` tests in `permissions.rs` enforce fail-closed non-interactive refusal. |
| **4. Progress & Feedback** | Real-time reactive `StatusSpinner` with animated Braille frames, phase indicators, and duration clocks. | `SubstrateObserver` pipeline dispatches events to in-place terminal status lines. |
| **5. Review & Decision** | Interactive, virtualized `DiffReviewer` with syntax highlighting, viewport bounding, and `j/k`/`Space` navigation. | `DiffReviewer` handles arbitrary diff lengths with alternate screen RAII cleanup. |
| **6. Context & State** | Persistent `AgentSession` tracking multi-turn conversation logs and linking to `SessionStateCheckpoint`. | Session serialization and stage resumption verified in `session.rs`. |
| **7. Interaction Design** | Standardized terminal design tokens (`Theme`, `Symbols`), keyboard-first navigation, and clear visual hierarchy. | Unified styling primitives in `crates/replayfix-cli/src/ui.rs`. |
| **8. Error & Recovery** | Human-readable failure diagnostics with actionable remediation tips and preserved triage reports. | Failures present diagnostic cards with clear recovery instructions. |
| **9. Trust & Transparency** | Delineates model proposals from substrate proofs; Merkle receipts (`audit_receipt.json`) with Ed25519 signatures. | Provenance badges and Merkle verification intact. |
| **10. Session & Workflow** | Multi-task continuity; preserves session history across multiple bug reproductions without restart. | `AgentSession::record_turn` persists to `.replayfix/session_state.json`. |
| **11. Terminal Ergonomics** | Cross-platform raw mode (`crossterm`), resize recalculation, and automatic fallback for pipes and CI. | Tested in headless CI and non-interactive redirects (`agent_ux.rs`). |
| **12. Developer Experience** | Zero-command onboarding, self-documenting `/help`, and 100% backward compatibility for all v1.3 CLI scripts. | All 47 existing CLI integration tests pass with 0 regressions. |
