# ReplayFix v1.5.0 Release Notes — Permanent Inoculation, Agentic Protocol (MCP) & Continuous CI/CD Automation

**Release Date**: 2026-11-01  
**Milestone**: Release 1.5.0 (`Spec 150`)  
**Status**: General Availability / Production Standard  
**Theme**: Autonomous Verification, Permanent Codebase Inoculation ("Dreaming"), Model Context Protocol (MCP) Server, Gate 3 Concurrency Quorum, and Enterprise CI/CD Integration

---

## Executive Summary

ReplayFix Release 1.5 evolves the platform from an interactive human-in-the-loop terminal assistant into a **universal verification, permanent inoculation, and continuous CI/CD platform**. While preserving 100% backward compatibility with all prior releases ($\Delta	ext{compat} = 0$) and strict repository isolation ($\Delta	ext{repo} = 0$), v1.5.0 introduces six core architectural pillars that bridge human developers, automated CI/CD pipelines, and external AI coding agents (Cursor, Windsurf, Claude Code, Antigravity).

---

## The 6 Architectural Pillars of v1.5.0

| Pillar | Implemented Capability in v1.5.0 | Verification Evidence |
| :--- | :--- | :--- |
| **1. Permanent Codebase Inoculation ("Dreaming")** | Synthesizes idiomatic `@playwright/test` TypeScript specs (`tests/repro/rf_<id>.spec.ts`) from grounded accessibility locators (`getByRole`, `getByText`, `getByTestId`) with zero positional anti-patterns; maintains tamper-evident `.replayfix/inoculations.json` registry (`contracts/inoculation.json`). | `crates/replayfix-core/src/inoculate.rs`, `replayfix inoculate --bug RF-01`, `repro --inoculate`. |
| **2. Model Context Protocol (MCP) Universal Server** | JSON-RPC 2.0 server (`replayfix mcp --transport stdio\|sse --port <port>`) exposing 5 tools (`replayfix_reproduce`, `replayfix_verify_patch`, `replayfix_inoculate`, `replayfix_inspect_trace`, `replayfix_doctor`), 3 resources (`replayfix://receipts/{task_id}`, `replayfix://sessions/{session_id}`, `replayfix://benchmarks`), and `triage_bug` prompt (`contracts/mcp_tools.json`). | `crates/replayfix-cli/src/mcp/` (`mod.rs`, `stdio.rs`, `sse.rs`). |
| **3. Autonomous Git Branch & PR Packager** | Packages verified fixes and inoculation specs onto isolated branches (`replayfix/fix-<bug_id>`), signs commits with Ed25519 + RFC 6962 Merkle trailers (`ReplayFix-Verified`, `ReplayFix-Merkle-Root`, `ReplayFix-Signature`), and emits the Evidence Matrix PR description (`pr_description.md`). | `crates/replayfix-cli/src/git_packager.rs`, `repro --package-pr`. |
| **4. Gate 3 Concurrency Perturbation & Stress Quorum** | Subjects Gate 2 candidates to simulated 3G network latency/jitter (`SET_NETWORK_PERTURBATION`, up to 500ms) and a 3-pass randomized-interval concurrency quorum; quarantines flaky patches with `FLAKY_NON_DETERMINISTIC` (Exit Code 21). | `crates/replayfix-core/src/stress.rs`, `repro --stress-quorum`, `--mock-flaky`. |
| **5. Multi-Modal Conversational Copilot & Ambiguity Picker** | Renders ASR spoken narration aligned with video keyframes (`/trace`), prompts an interactive terminal locator picker on candidate score ties ($\|\Delta	ext{score}\| < 0.05$ / `500` bps), and streams live CDP/console/network events via `SubstrateEvent`. | `crates/replayfix-core/src/locator.rs`, `crates/replayfix-cli/src/shell.rs`. |
| **6. CI/CD Action & Headless SARIF / JUnit Reporters** | Exports SARIF v2.1.0 (`results.sarif`) for GitHub Code Scanning and JUnit XML (`junit.xml`) for CI test dashboards; provides a composite GitHub Actions `action.yml`. | `crates/replayfix-core/src/reporters.rs`, `action.yml`, `--sarif`, `--junit`. |
