# Release Notes: ReplayFix v1.9.0

**Release Tag**: `v1.9.0`  
**Release Date**: 2026-11-03  
**Architecture Theme**: Pure Application-Agnostic Verification & High-Throughput Parallel Swarm Benchmark Engine  

---

## 1. Executive Summary
ReplayFix v1.9.0 delivers complete decoupling from hardcoded fixture registries, permanently deprecating `"has no built-in fixture for task"`. Any uninstrumented modern web application (React, Vite, Next.js, Create-React-App, Remix, Express) can now be autonomously verified, repaired, and regression-inoculated based solely on generic observable signals (uncaught exceptions, failed network mutations, and DOM interaction telemetry).

Simultaneously, v1.9.0 introduces the **High-Throughput Parallel Swarm Benchmark Engine** (`replayfix sweep`), executing the complete 20-defect MetaPulse benchmark suite (`RF-01` through `RF-20`) in ~21.6 seconds across concurrent workers, emitting an RFC 6962 transparency log and Ed25519-signed Merkle batch root.

---

## 2. Key Capabilities & Features

### A. Pure Application-Agnostic Execution Engine
- **Permanent Extinction of Static Fixture Dependency**: ReplayFix no longer requires tasks to exist in a built-in static enum. Unindexed tasks dynamically boot, ground, and evaluate with 100% confidence.
- **Universal Dev Server Detection (`ManagedSpaServer`)**: Ephemeral port binding (`127.0.0.1:0`) with automatic toolchain discovery across Vite, Next.js, Create React App, and vanilla Node servers.
- **Generic Defect Signals**: Eliminated hardcoded DOM selectors in favor of generic observable criteria:
  - Uncaught page exceptions (`pageerror`)
  - Failed network mutation responses (`status >= 400`)
  - Interaction-driven DOM mutation verification
- **Dynamic Repro Spec Synthesis**: Autonomous generation of Playwright reproduction specifications frozen via pre-flight SHA-256 test hash to eliminate test tampering.

### B. High-Throughput Parallel Benchmark Swarm Engine (`replayfix sweep`)
- **Concurrent Worker Pool**: Configurable worker allocation (`--parallel <N>`) with work-stealing queue distribution and zero lock contention.
- **Zero Base Repo Mutation ($\Delta\text{repo} = 0$)**: Every worker operates within an isolated ephemeral OS temp scratch directory; strict pre/post worktree manifest verification guarantees 0 base repository pollution.
- **Real-Time Fleet Telemetry Aggregator**: Real-time emission of `telemetry_matrix.json` and `benchmark_summary.json` conforming strictly to JSON schema contracts.
- **Cryptographic Batch Notary**: Aggregation of individual task leaf receipts into an RFC 6962 Merkle tree with Ed25519 batch signature verification.
