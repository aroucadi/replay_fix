## 1. Executive Summary

**ReplayFix v1.3.0** (`Spec 130`) enforces strict execution-derived provenance and billing integrity across all receipts, eliminates synthetic HTML fixture fallbacks when operating on real repositories, and delivers **Universal Modern Web SPA Ingestion** in both **Attached Mode** (`--url <endpoint> --repo <path>`) and **Managed Mode** (`--repo <path>`):

1. **Execution-Derived Provenance & Billing Integrity**:
   - `provenance` and `model_provenance` in `audit_receipt.json` are derived strictly from verified runtime execution telemetry (`repair_telemetry.provider_mode == "live-meta-muse-api"` or `video_telemetry.sam_snap.model == "sam-3.1"`).
   - Combining `--mode live-ai` with any offline mock flag (`--mock-syntax-retry`, `--mock-failing-repair`, `--mock-pkg-test-mutation`, or `--mock-patch != "builtin"`) is rejected upfront with `ERR_USAGE` (Exit Code `2`).
   - Deterministic fixture runs always emit `"provenance": "deterministic-fixture"`, `"model_provenance": null`, and `"token_accounting": null`, maintaining 100% consistency with `"Zero live external AI tokens billed"`.
   - `replayfix run --bug <ID>` executes the two-gate verification loop directly and writes `.replayfix/audit_receipt.json` without requiring `--mock-heal`.
2. **Universal SPA Attached Mode (`--url <endpoint> --repo <path>`)**:
   - Added `--url <endpoint>` to `ReproArgs` and `AttachedSpaEndpoint` in `crates/replayfix-core/src/environment.rs`.
   - Bypasses the internal static file server, connects Playwright CDP directly to `<endpoint>`, observes Gate 1 RED, applies bounded repair to `--repo`, verifies 2-run Gate 2 GREEN stability, and rolls back `--repo` if Gate 2 fails.
3. **Managed SPA Ingestion (`--repo <path>`)**:
   - Implemented `ManagedSpaServer` and `SpaToolchain` (`Vite`, `NextJs`, `ReactScripts`, `NodeScript`) in `crates/replayfix-core/src/environment.rs`.
   - Inspects `package.json`, spawns an ephemeral child dev server on dynamic port `:0`, captures the assigned port from stdout/stderr, polls HTTP readiness up to a 30s timeout, and enforces RAII `Drop` cleanup via `Platform::terminate_process_tree`.
4. **Decoupled Real Repositories from Static HTML Fixtures**:
   - Added the runnable MetaPulse SPA workspace in `benchmarks/metapulse/` (`package.json`, `server.js`, `public/index.html`, `public/app.js`).
   - Removed temporary synthetic `#btn-publish-quote` elements from `RF01_INDEX_HTML` and inline HTML strings from `Fixture::metapulse_rf01()`.
