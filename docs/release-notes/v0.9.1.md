## 2. Key Zero-Trust Remediations & Hardening

### 2.1 4-Layer Cryptographic Receipt & On-Disk Artifact Verification (`replayfix-core::receipt`, `replayfix-cli`)
- **Layer 1 (On-Disk Artifact Integrity)**: `AuditReceipt::verify_receipt_and_attestation` now verifies that every `EvidenceLeaf` recorded in `merkle_receipt.json` corresponds to an existing file in `<output_dir>/artifacts/<file_name>` whose on-disk byte length matches `leaf.size_bytes` and whose raw SHA-256 digest matches `leaf.content_sha256`. Post-run tampering with `01_candidate.diff`, `02_preflight.json`, or `audit_receipt.json` on disk now deterministically fails closed with `MERKLE_PROOF_INVALID` (Exit Code `40`).
- **Fail-Closed Missing Merkle Receipt**: Deleting `merkle_receipt.json` and invoking `replayfix verify-receipt .replayfix/audit_receipt.json` no longer falls back to signature-only verification; it fails closed with Exit Code `40`.
- **Top-Level `audit_receipt.json` Binding**: `AuditReceipt::write_disaggregated_artifacts` writes `04_audit_receipt.json` as the pre-Merkle core receipt leaf, computes the RFC 6962 Merkle root and Ed25519 attestation, populates `self.merkle_root` and `self.attestation`, and atomically rewrites `<output_dir>/audit_receipt.json` so both single-bug runs and 5-bug sweep runs carry complete cryptographic metadata.
- **Sweep Receipt Verification**: `replayfix verify-receipt .replayfix/sweep_receipt.json` now reconstructs the 5-bug sweep Merkle tree from the on-disk `<BUG_ID>/audit_receipt.json` (or `triage_report.json`) artifacts and verifies the sweep Merkle root and Ed25519 attestation.

### 2.2 Strict RFC 6962 Merkle Proof & Tree-Size Invariants (`replayfix-core::merkle`)
- **Audit Path Exhaustion at `size == 1`**: `MerkleInclusionProof::verify_node` now rejects non-empty trailing `audit_path` elements when `size == 1`, preventing malformed or over-length proofs from passing verification.
- **Tree-Size & Leaf-Index Binding**: `MerkleReceipt::verify_all` enforces `schema_version == "0.9"`, `self.tree_size == self.leaves.len()`, `proof.tree_size == self.tree_size`, `proof.leaf_index == idx`, and uniqueness of `leaf.file_name` across the tree.

### 2.3 RFC 8785 Canonical JSON UTF-16 Code-Unit Sorting (`replayfix-core::digest`)
- Object keys in `digest::canonical_json` are sorted in strict UTF-16 code-unit order (`a.encode_utf16().cmp(b.encode_utf16())`) per RFC 8785 Section 3.2.3, with unit test verification covering supplementary-plane surrogate pairs (`\u{10000}` vs. BMP `\u{E000}`).

### 2.4 Persistent & Environment-Driven Ed25519 Key Provisioning (`replayfix-core::crypto`)
- Implemented `KeypairManager::load_or_generate` conforming to `ADR-03`:
  1. Checks `REPLAYFIX_SIGNING_KEY` environment variable (failing closed if set to invalid hex).
  2. Loads or atomically persists `<output_dir>/keys/ed25519_signing.key` and `ed25519_signing.pub` via `atomic_write_file`.

### 2.5 Sweep Contract Alignment & Bounded Concurrent `ModelPool` (`replayfix-core::sweep`, `replayfix-core::repair`)
- **Schema Harmonization**: Synchronized `contracts/sweep_receipt.schema.json` with `SweepReceipt` (`schema_version`, `total_bugs`, `repaired_bugs`, `failed_bugs`, `results`, `merkle_root`, `ed25519_attestation`, `elapsed_wall_clock_ms`, `created_at`) with zero floating-point fields.
- **Sweep Worktree Integrity & Atomic Persistence**: `run_sweep` now captures pre- and post-sweep `WorktreeManifest` snapshots on `base_repo` ($\Delta	ext{repo}=0$), honors `options.live_browser`, and writes `sweep_receipt.json` via `atomic_write_file`.
- **Bounded Concurrent `ModelPool`**: `ModelPool::race_candidates` dispatches candidate generation across bounded scoped worker threads (`max_concurrent_tasks`) and enforces `timeout_per_task`.
