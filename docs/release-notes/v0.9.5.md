## 1. Executive Summary

**ReplayFix v0.9.5** delivers **Spec 095 — The Offline Judge Proof Portal & Live Multimodal Cloud Gateway** atop the independently qualified `v0.9.1` cryptographic foundation:

1. **Self-Contained Offline Judge Proof Portal (`proof_viewer.html`)**:
   - Single-file HTML5/CSS3/ES2022 application with strict offline Content Security Policy (`default-src 'none'; connect-src 'none'`) and zero external dependencies or network calls.
   - Implements client-side **RFC 8785 UTF-16 canonical JSON**, **RFC 6962 SHA-256 leaf (`0x00`) and internal node (`0x01`) Merkle hashing**, and **pure RFC 8032 Ed25519 curve verification** in JavaScript, verified bit-for-bit against `replayfix-core` in automated Node.js parity tests.
   - Enforces six distinct, honest verification states: `VERIFIED GENUINE`, `SIGNATURE VALID — SIGNER UNTRUSTED`, `INTEGRITY CHECK FAILED`, `UNSIGNED RECEIPT`, `UNSUPPORTED PROTOCOL VERSION`, and `MALFORMED RECEIPT`.
   - Includes interactive panels for Merkle Proof Exploration, Ed25519 Signature & Pinned Trust Store management, Multimodal Video/DOM/SAM 3.1 Spatial Grounding, Unified Diff & Active Regression Parity ($F_{	ext{patched}} \setminus F_{	ext{baseline}} = \emptyset$), and the 5-Bug MetaPulse Benchmark Sweep (`RF-01`..`RF-05`).
2. **Bounded Live Multimodal Cloud Gateway (`replayfix-core::gateway`)**:
   - Supports Meta Model API (`https://api.meta.ai/v1/responses` for `muse-wonder-1.0`, `muse-spark-1.3`, `sam-3-1`, and `muse-voice-transcribe-1.0`) and Baseten open-weight fallback (`https://inference.baseten.co/v1` `meta-models/muse-spark-open`).
   - Enforces token-bucket `RatePool` (RPM, TPM, `max_in_flight`), HTTP 429 `Retry-After` + bounded exponential backoff with jitter, a 3-state `CircuitBreaker` (`Closed`, `Open`, `HalfOpen`), the **Zero-Audio Rule** on text/code models, 24 kHz mono PCM WAV header verification, and automatic credential redaction (`[REDACTED]`).
3. **CLI Proof Bundle Exporter (`replayfix export-proof`)**:
   - Exports `proof_viewer.html` and deterministic cryptographic demo presets (`demo_presets.json`) via atomic worktree writes.
