## 1. Executive Summary

**ReplayFix v1.2.0** completes the live multimodal perception pipeline (`Spec 120`) and enforces strict zero-deception provenance across both `--mode live-ai` and `--mode deterministic-fixture`:

1. **Live Meta SAM 3.1 Wire Segmentation (`sam-3.1`)**:
   - Implemented `SamWirePayload` and `MetaGatewayClient::send_sam_segmentation` (`crates/replayfix-core/src/gateway.rs`) and `SamSegmenter::segment_live` (`crates/replayfix-core/src/perception.rs`) over `POST https://api.meta.ai/v1/responses`.
   - Parses SAM 3.1 wire tokens (`<|box;x1=...;y1=...;x2=...;y2=...|><|mask;...|>`), snaps interaction hotspots to calibrated CSS centroids, and enforces CDP `document.elementFromPoint` hit-testing with fail-closed `AMBIGUOUS_GROUNDING` (Exit Code `22`).
2. **Live Muse Voice 24 kHz PCM ASR (`muse-voice-transcribe-1.0`)**:
   - Implemented `AsrPayload` (`PCM_24KHZ`, `ENDPOINTING`, `DELTA`), strict 44-byte RIFF/WAVE header validation (`24,000 Hz`, mono, 16-bit PCM), `MetaGatewayClient::send_asr_transcription`, and `AsrTranscriber::transcribe_live` / `parse_asr_events`.
3. **Multi-Action Trajectory Extraction (`ActionTrajectory`)**:
   - Added `RoiDiffer::detect_trajectory` (`crates/replayfix-core/src/video.rs`) and `ActionTrajectory` / `UserAction` (`click`, `input`, `navigate`) sequencing in `VideoTelemetry`.
4. **Honest Offline vs. Live Provenance & Global Credential Resolution**:
   - Offline `--mode deterministic-fixture` explicitly stamps `sam_snap.model = "local_diff_heuristic"`, `narration.model = "simulated_fixture"`, and omits `model_provenance` so offline runs never claim live cloud model execution.
   - `GatewayConfig::default()` resolves `META_API_KEY` / `REPLAYFIX_AI_KEY` from process environment variables, `.env` files (supporting `KEY="val"`, `$env:KEY = "val"`, and `export KEY="val"`), and Windows User/Machine Registry (`HKCU\Environment` / `HKLM\...\Environment`).
