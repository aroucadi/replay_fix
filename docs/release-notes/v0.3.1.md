# Release Notes — FixTream / ReplayFix v0.3.1

**Release Date**: 2026-10-27  
**Tag**: `v0.3.1`  
**Milestone**: Terminal UX & Interaction Engineering Patch

---

## Summary

FixTream / ReplayFix **v0.3.1** introduces a cohesive, modern, and accessible terminal user experience. Inspired by the clarity and restraint of tools like Cargo and modern CLI engineering practices, this patch transforms raw plain-text output into a structured, responsive, and visually polished terminal interface while preserving 100% of underlying domain logic, verification schemas, exit codes, and cross-platform compatibility.

---

## Key Improvements

### 1. Unified Visual Identity & Design Tokens (`crates/replayfix-cli/src/ui.rs`)
- **Semantic Color Palette**: Distinct yet restrained ANSI color styles (Bright Cyan brand accents, Bright Green for verified states, Bright Red for failures, Bright Yellow for warnings, Bright Blue for informational steps, and Dim Gray for metadata).
- **Accessible Symbols**: Standard status symbols (`✔`, `✖`, `▲`, `◆`, `→`) paired with clear textual descriptors and plain-text fallbacks so meaning is never communicated through color alone.
- **Section Headers & Field Alignment**: Consistent section header banners (`FixTream // Section Title`) and neat key-value alignment.

### 2. Standard Terminal Capability & Color Policy Detection
- Native implementation respecting:
  - `NO_COLOR` (disables all color output when set).
  - `CLICOLOR_FORCE` (forces color output when set to non-zero).
  - `TERM=dumb` (disables ANSI escape sequences).
  - `std::io::IsTerminal` for automatic detection of piped, redirected, or CI environments.

### 3. Step-by-Step Progress & Diagnostic Hierarchy
- **`doctor` Diagnostics**: Enhanced tabular output with clear status badges (`✔ [OK]`, `✖ [MISSING]`, `▲ [OUTDATED]`) and contextual remediation advice.
- **`repro` Ingestion & Dual-Gate Output**: Live step markers tracking scratch sandbox isolation, Gate 1 baseline reproduction, disk-backed patch application, and Gate 2 verification.
- **Clean Stream Separation**: Error and security violation notifications emit to stderr with semantic badges; JSON outputs (`--json` and receipts) remain pristine on stdout without ANSI noise.
