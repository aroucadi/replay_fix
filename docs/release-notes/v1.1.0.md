## 1. Executive Summary

**ReplayFix v1.1.0** upgrades the benchmark suite and cloud gateway with:
1. **Real MetaPulse 20-Bug Benchmark Suite (`RF-01` through `RF-20`)**:
   - Migrated all 20 real MetaPulse `.mp4` defect recordings (`benchmarks/metapulse/videos/RF-01_*.mp4` through `RF-20_*.mp4`) and `BENCHMARK_METADATA.md`.
   - Generated the immutable cryptographic `benchmarks/metapulse/MANIFEST.json` recording filename, byte size, SHA-256 digest, bug ID, title, and target branch (`bug/RF-01`..`bug/RF-20`).
   - Added `MetaPulseManifest` and `MetaPulseRepoRunner` (`https://github.com/aroucadi/MetaPulse.git` branch checkout/clone) in `replayfix-core::fixtures`, archiving the 5 toy shopping-cart cases in `tests/fixtures/toy_cart/`.
2. **Production HTTPS `MetaGatewayClient` (`reqwest` + `rustls-tls`)**:
   - Added `MetaGatewayClient` in `crates/replayfix-core/src/gateway.rs` using `reqwest` with pure-Rust `rustls-tls`, 30s connect / 90s read timeouts, `META_API_KEY` (or `REPLAYFIX_AI_KEY`) Bearer authentication, HTTP 429/503 exponential backoff, and `<UNTRUSTED_DOM_CONTEXT>` XML escaping.
   - Configured model support for `sam-3.1`, `muse-spark-1.3` (fallback `meta-llama/Llama-3.2-11B-Vision-Instruct`), `muse-wonder-1.0` (fallback `meta-llama/Llama-3.3-70B-Instruct`), and `muse-voice-transcribe-1.0`.
3. **Honest Dual Execution Modes (`--mode live-ai` vs. `--mode deterministic-fixture`)**:
   - Added `--mode <live-ai | deterministic-fixture>`, `--model-intent <MODEL_ID>`, and `--model-repair <MODEL_ID>` to `replayfix run`.
   - `--mode live-ai` fails closed immediately with Exit Code `30` (`ERR_GATEWAY_AUTH_MISSING`) if `META_API_KEY` / `REPLAYFIX_AI_KEY` is unconfigured.
   - `--mode deterministic-fixture` uses calibrated responses from `benchmarks/fixtures/` and records `provenance: "deterministic-fixture"` and `model_provenance` in `audit_receipt.json`.
4. **Authentic Option B Demonstration Video**:
   - Generated `release/v1.1.0/demo/replayfix-v1.1.0-demo.mp4` (`10.16 MB`, `1920x1080`, `30fps`, `180.0s`) from the real MetaPulse cursor recordings (`RF-01_quote_repost_crash_with_cursor.mp4`, `RF-02_stale_follower_increment.mp4`, `RF-03_character_counter_underflow.mp4`).
