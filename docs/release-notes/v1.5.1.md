# ReplayFix v1.5.1 Release Notes — Live Meta Multimodal Wire Protocol & Full Muse Model Utilization

**Release Date**: 2026-11-01  
**Milestone**: Release 1.5.1 (`Spec 151`)  
**Status**: General Availability / Production Standard  
**Theme**: Production Wire Protocol Alignment Across All 5 Meta Model API Modalities (`sam-3.1` Image & Video, `muse-voice-transcribe-1.0` Multipart WAV, `muse-spark-1.3` Web Search Tool Calling, `muse-wonder-1.0` Repair, and `muse-image-1.0` Visual Badge Generation)

---

## Summary of Changes

1. **Live `sam-3.1` Image & Video Segmentation (`POST /v1/responses`)**:
   - `MetaGatewayClient::send_live_https_with_image` and `segment_keyframe_sam31` now format multimodal requests using the canonical `input` message array (`{"type": "input_image", "image_url": "data:image/png;base64,..."}`), incrementing `usage.images_processed` (`Images segmented`).
   - Added `MetaGatewayClient::segment_video_sam31` dispatching `{"type": "input_video", "video_url": "data:video/mp4;base64,..."}` to `sam-3.1`, incrementing `usage.video_frames_processed` (`Video frames segmented`).
   - Extended `SamSegmenter::parse_wire_tokens` to support 6-attribute `<|box;x1=...;y1=...;x2=...;y2=...;w=...;h=...|>` tokens returned by live `sam-3.1`.
2. **Live `muse-voice-transcribe-1.0` Multipart WAV ASR (`POST /v1/asr/transcribe`)**:
   - `MetaGatewayClient::transcribe_audio_wav` now constructs an RFC 7578 `multipart/form-data` payload containing part `request` (`{"model":"muse-voice-transcribe-1.0","audioEncoding":"WAV"}`) and part `audio` (`audio.wav`), and `AsrTranscriber::parse_asr_events` maps `audioDurationMs` (`Audio transcription seconds`).
3. **Live `muse-spark-1.3` Native Tool Calling (`web_search`) & `muse-image-1.0` Badge Generation**:
   - Added `MetaGatewayClient::query_web_search_grounding` attaching `"tools": [{"type": "web_search"}]` (`Tool calls` / `Web searches`).
   - Added `MetaGatewayClient::generate_verification_badge` calling `POST /v1/images/generations` with `model: "muse-image-1.0"` (`Images`) and writing `.replayfix/keyframes/muse_verification_badge.b64`.
