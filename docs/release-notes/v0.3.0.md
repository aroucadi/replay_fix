# Release Notes — ReplayFix v0.3.0

**Release Date**: 2026-10-27
**Tag**: `v0.3.0`
**Specification**: `specs/030-v0.3-ephemeral-scratch-isolation`

---

## Summary

ReplayFix **v0.3.0** introduces **ephemeral scratch workspace isolation**, **dual-layer base repository integrity verification ($\Delta \text{repo} = 0$)**, **dynamic OS ephemeral port allocation (`127.0.0.1:0`)**, and **cross-platform process tree supervision with Windows file-lock defense**.

Previously, in v0.2.x, the simulated two-gate loop (`Gate 1 RED` → `Repair` → `Gate 2 GREEN`) operated purely on in-memory strings. With v0.3.0, every verification run snapshots the target repository (`--repo`), clones its working tree into an isolated OS temporary directory (`ScratchSandbox`), allocates an ephemeral loopback port (`EphemeralPort`), applies candidate patches to disk inside the scratch sandbox, re-verifies that the user's base repository remained bit-for-bit untouched across both SHA-256 content hashes and `git status --porcelain`, and tears down all child processes and temporary files before exiting.

---

## Highlights & New Capabilities

### 1. Dual-Layer Repository Integrity (`WorktreeManifest`)
- **Layer 1 (Content Tree SHA-256)**: Recursively walks the workspace, computes SHA-256 digests over every non-excluded regular file (`FileEntry { path, size, sha256 }`), and hashes the RFC 8785 canonical JSON array into `tree_sha256`.
- **Layer 2 (Git Porcelain Status)**: When `.git` is present, runs `git -C <root> status --porcelain=v1 -uall` and compares pre-run and post-run status lines.
- **Fail-Closed Mutation Detection**: If any file in the base repository is modified, added, or deleted during a run, `pre_manifest.verify_unchanged(&post_manifest)` fails closed and writes `triage_report.json` with `status: "BASE_REPO_DIRTY_MUTATION_DETECTED"` (exit code `11`).

### 2. Ephemeral Scratch Sandbox (`ScratchSandbox`) & Windows File-Lock Defense
- Creates a unique directory in `std::env::temp_dir()` (`replayfix-sandbox-<task_id>-<pid>-<seq>`) and copies non-excluded working files from `--repo`.
- Validates all sandbox file operations (`read_file`, `write_file`, `resolve_safe_path`) against path traversal (`../`), UNC paths, DOS device names, ADS streams, and symlink escape chains.
- Enforces a 32 MiB per-file safety limit (`MAX_WORKSPACE_FILE_BYTES`) to prevent out-of-memory or disk exhaustion DoS.
- Implements `teardown()` and `Drop` with automatic child process tree termination, recursive read-only attribute clearing (`permissions.set_readonly(false)`), and bounded retry backoff (`10ms`, `25ms`, `50ms`, `100ms`, `200ms`) so Windows file locks (`os error 5` / `os error 32`) never leak temporary directories.

### 3. Dynamic Ephemeral Port Allocation (`EphemeralPort`) & Process Tree Supervision
- `EphemeralPort::allocate()` binds `127.0.0.1:0` and returns a `NonZeroU16`-backed port, guaranteeing zero hardcoded port collisions across concurrent runs.
- `Platform::terminate_process_tree(pid)` kills entire child process trees (`taskkill /F /T /PID` on Windows, `pkill -KILL -P` / `kill -9` on Unix) while rejecting PID `0` and `std::process::id()`.

### 4. Receipt Schema `"0.3"`
`audit_receipt.json` is bumped to `schema_version: "0.3"` and now records:
- `base_tree_sha256`: 64-char hex SHA-256 of the base repository's `WorktreeManifest`.
- `sandbox_tree_sha256`: 64-char hex SHA-256 of the scratch sandbox's `WorktreeManifest` after patch application.
- `base_repo_unmodified_verified`: boolean (`true`) proving $\Delta \text{repo} = 0$.
- `ephemeral_port`: dynamically allocated OS port (`u16`).

## Known Limitations & Next Steps

- **Simulated Oracle**: While Gate 1, patch application, and Gate 2 now execute on disk inside an isolated `ScratchSandbox` with real $\Delta \text{repo} = 0$ verification and ephemeral port allocation, the gate oracle itself still statically inspects `src/cart-summary.js` for task `RF-01`.
- **Upcoming Milestone (`v0.4.0`)**: Spec 040 (`040-v0.4-playwright-cdp-grounding`) will wire Playwright CDP browser execution, `ariaSnapshot` DOM inspection, and spatial coordinate snapping into the isolated scratch sandbox and ephemeral port pipeline built in v0.3.0.
