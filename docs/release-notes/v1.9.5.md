# Release Notes: ReplayFix v1.9.5

**Release Tag**: `v1.9.5`  
**Release Date**: 2026-11-03  
**Architecture Theme**: Spec 195 — Living Cybernetic Command Deck (24-Bit Truecolor, 60 FPS Motion Engine & Double-Buffered Bento TUI)  

---

## 1. Executive Summary
ReplayFix v1.9.5 transforms the CLI and interactive TUI layer (`crates/replayfix-cli/src/ui.rs` and `crates/replayfix-cli/src/tui/*`) from a traditional 16-color terminal interface into a **Living Cybernetic Command Deck** inspired by Claude Code, Charm Lipgloss/Bubbles, and Lazygit.

---

## 2. Architectural Highlights

### A. ReplayFix Signature Brand Identity (`tui/brand.rs`)
- **Hero Splash Banner (`render_hero_splash`)**: Geometric Unicode block logotype combining the playback triangle `▶` and causal bug target `󰒓 / ⬢`, rendered with an algorithmic 4-stop 24-bit Truecolor horizontal gradient fading across character columns:
  `Electric Cyan (#00d2ff) ──> Cyber Violet (#7928ca) ──> Phosphor Amber (#f59e0b) ──> Substrate Emerald (#10b981)`
  paired with the metadata ribbon:
  `▶ REPLAYFIX // Autonomous Bug Reproduction, Causal Verification & Repair`
  `[ v1.9.0 ] [ Rust Substrate: 60 FPS ] [ Meta AI: Spark 1.3 + Wonder 1.0 ]`
- **Compact HUD Emblem (`render_compact_hud_emblem`)**: Dual-segment micro-pill badge (`\x1b[48;2;18;24;38m\x1b[38;2;56;189;248m ▶⚡ REPLAYFIX \x1b[48;2;30;41;59m\x1b[38;2;148;163;184m v1.9.0 \x1b[0m`) with automatic collapse when terminal columns `< 80` and clean ASCII degradation under `NO_COLOR` / non-TTY streams.

### B. 24-Bit Truecolor Design System & Rounded Box Geometry (`ui.rs`, `tui/dialog.rs`, `intent.rs`)
- **24-Bit Truecolor (`CyberPalette`)**: All foreground (`\x1b[38;2;R;G;Bm`) and background (`\x1b[48;2;R;G;Bm`) tokens use full 24-bit RGB (`#38BDF8` Cyber Cyan, `#10B981` Matrix Emerald, `#F59E0B` Solar Amber, `#F43F5E` Crimson Alert, `#A855F7` Neural Violet).
- **Background-Filled Pill Badges**: Status indicators (`PASS`, `FAIL`, `WARN`, `RUN `, `SKIP`) and hotkey hints (`Enter: Approve`, `Tab: Cycle`, `j/k: Scroll`) render as high-contrast background-filled pill badges (`\x1b[48;2;...m`).
- **Rounded Unicode Box Frames**: Banners, security boundary cards, execution plans, and interactive views use rounded Unicode box geometry (`╭───╮`, `│ ... │`, `╰───╯`).

### B. 60 FPS Living Motion Engine (`tui/motion.rs`, `tui/spinner.rs`, `shell.rs`)
- **8-Level Fractional Progress Bars**: Sub-character progress bars using `▏▎▍▌▋▊▉█` (`1/8`th cell resolution) interpolated across a Cyber Cyan to Emerald gradient.
- **Traveling RGB Wave Shimmer**: Sinusoidal luminance wave traveling across active agent deliberation and tool status strings at 60 FPS.
- **Breathing Idle Prompt**: Smooth 1.5s (`90`-frame) luminance pulse on the `❯` prompt character.
- **Animated Gate Flash Transitions**: Passing verification gates trigger a momentary emerald row highlight that smoothly decays into a muted passed state.

### C. Bento Terminal Layout & Double-Buffered Differential Renderer (`tui/layout.rs`, `tui/diff_view.rs`)
- **Differential Frame Rendering**: `FrameBuffer` and `DifferentialRenderer` diff consecutive frames and emit ANSI cursor jumps (`\x1b[{row};{col}H`) only for changed cells/lines, eliminating `Clear(ClearType::All)` full-screen redraw blink.
- **80x24+ Bento Command Deck**:
  - **Header Deck**: Displays active repository, `󰊢` branch badge, `:0` ephemeral port badge, and live token rate meter (`tok/s`).
  - **Dual-Pane Body**: Left Pane Live Agent Thought Stream & Tool Event Log with Nerd Font glyphs (`󰈚` spec, `⚡` spark, `󰒓` core); Right Pane Virtualized Diff Reviewer with line-number gutters, hunk headers, and 24-bit syntax token coloring.
  - **Sticky Dock**: Inverted background command pills for keyboard navigation.

### D. Zero-Panic & Non-TTY Compliance
- **BeautifulRust Law X**: `0` `.unwrap()`, `0` `.expect()`, and `0` panics across all production code.
- **RAII Terminal Restoration & Non-TTY Fallback**: `ScreenGuard` and the global terminal panic hook cleanly exit raw mode and the alternate screen on termination; non-TTY pipes and CI environments automatically degrade to clean unformatted output.
