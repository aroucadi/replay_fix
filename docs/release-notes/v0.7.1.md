## 1. Executive Summary

ReplayFix `v0.7.1` closes every gap and hardening item identified in the clean-room adversarial audit of Spec 070.

This patch release transitions ReplayFix from data-model readiness into active execution wiring:
1. **Real Regression Parity Execution**: `RegressionEvaluator::evaluate` is actively executed during both live browser and simulated runs against captured or synthesized baseline and patched test snapshots. Candidate repairs that introduce regressions are immediately rejected with `TriageStatus::RegressionDetected` and exit code `31`.
2. **Dedicated DiffGuard Module**: Formalized `DiffGuard` (`crates/replayfix-core/src/diffguard.rs`) with structural `package.json` AST inspection and runner configuration boundary protection (`CONFIG_MUTATION_PROHIBITED`, exit code `11`).
3. **CheckpointManager Orchestration**: Implemented `CheckpointManager` in `checkpoint.rs` to manage stage progression, disk persistence of `session_state.json`, and stale checkpoint detection.
4. **Real Git Ref Resolution**: Replaced zero-hash stubs with `resolve_git_ref` resolving commit SHAs against git history for `--clean-ref`.
5. **Codebase Inoculation CLI**: `freeze-spec` generates permanent Playwright regression tests (`tests/repro/rf_{id}_regression.spec.ts`) with cryptographic aggregate SHA-256 headers.
6. **Numbered Disaggregated Fact Artifacts**: Emits both named and Spec 070 numbered artifacts (`01_candidate.diff`, `02_preflight.json`, `03_differential_diagnosis.json`, `04_regression_parity.json`, `04_audit_receipt.json`).

## 2. Key Deliverables & Hardening

### 2.1 Dedicated DiffGuard Engine (`crates/replayfix-core/src/diffguard.rs`)
- Structured `DiffGuard::validate_patch` enforcing runner configuration immutability on `playwright.config.*`, `jest.config.*`, `vitest.config.*`, `tsconfig*.json`.
- Structural AST `package.json` parsing that locks down `"scripts.test*"` keys while permitting safe dependency updates.
- Re-exported in `replayfix_core::DiffGuard` and wired into `BlockPatcher::apply`.

### 2.2 Active Regression Parity Wiring (`crates/replayfix-core/src/engine.rs` & `regression.rs`)
- Added `RegressionEvaluator::capture_suite_snapshot` discovering structured test output files (`.replayfix/test-results.json`, `playwright-report/results.json`).
- Evaluates regression parity before advancing to Gate 2 Green.
- Rejects new failures ($F_{\text{patched}} \setminus F_{\text{baseline}} \ne \emptyset$), missing tests, and silent test skips with exit code `31` (`REGRESSION_DETECTED`).
- Added CLI flag `--mock-regression` and integration test `mock_regression_triggers_exit_31_and_triage_report`.

### 2.3 CheckpointManager & Monotonic Progression (`crates/replayfix-core/src/checkpoint.rs`)
- Implemented `CheckpointManager::init`, `advance`, `update_artifacts`, and `resume`.
- Enforces monotonic progression through all execution stages:
  `Initialized` $\to$ `ReproducedGate1Red` $\to$ `PatchProposed` $\to$ `PreflightPassed` $\to$ `VerifiedGate2Green` $\to$ `ParityLocked` $\to$ `ReceiptIssued`.
- Invalidation guards reject checkpoints when git HEAD or manifest tree SHA-256 changes or when TTL (default 3600s) expires.

### 2.4 Codebase Inoculation Generation (`crates/replayfix-cli/src/main.rs`)
- `replayfix freeze-spec --bug <ID>` synthesizes a permanent regression test at `tests/repro/rf_{id}_regression.spec.ts`.
- Embeds cryptographic metadata:
  - `REPLAYFIX-FROZEN-SPEC: <BUG>`
  - `AGGREGATE-SHA256: <HASH>`
  - `CONTRACT-DIGEST: <DIGEST>`
  - `FROZEN-AT: <TIMESTAMP>`

### 2.5 Complete Disaggregated Artifact Suite (`crates/replayfix-core/src/receipt.rs`)
- Writes disaggregated evidence artifacts into `<output_dir>/artifacts/`:
  - `01_candidate.diff` and `candidate.patch`
  - `02_repro_spec.json` and `02_preflight.json`
  - `03_differential_diagnosis.json` and `differential_diagnosis.json`
  - `04_regression_parity.json` and `regression_parity.json`
  - `04_audit_receipt.json`
