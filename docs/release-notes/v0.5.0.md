## 1. Executive Summary

Release `v0.5.0` delivers **Spec 050 (`050-v0.5-video-telemetry-ingestion`)**, upgrading ReplayFix from static fixture coordinates to a **multimodal video telemetry, spatial segmentation, and speech alignment pipeline**. Given a developer bug recording (`replayfix run --video assets/fixtures/rf01_demo.mp4 --repo .`), ReplayFix now:

1. Probes the video container with `ffprobe` (`VideoPreprocessor::probe_video`) under a bounded process deadline (`run_bounded`), verifying supported containers (`.mp4`, `.webm`, `.mov`), non-zero geometry, and duration $\le 120\text{s}$.
2. Isolates the interaction timestamp `t_ms` and rough hotspot `(x_video, y_video)` via a cursor-bounded $120 \times 120\text{px}$ ROI $L_1$ optical-flow frame differencer (`RoiDiffer::detect_interaction`), writing up to `MAX_KEYFRAMES = 10` keyframe PNGs to `.replayfix/keyframes/`.
3. Extracts 24 kHz mono 16-bit PCM audio (`PCM_24KHZ`) and aligns developer narration using **Meta Superpower #2 (`muse-voice-transcribe-1.0`)** with cumulative `audioProcessedMs` locking (`AsrTranscriber`), while enforcing the strict **Zero-Audio Rule** forbidding `muse-spark-1.3` from receiving audio.
4. Snaps the rough interaction coordinate to the exact UI element contour centroid using **Meta Superpower #1 (`sam-3.1`)** `<|box;x1=...;y1=...;x2=...;y2=...|><|mask;...|>` wire tokens (`SamSegmenter`), projects the centroid to CSS logical pixels via `GeometricCalibration::to_css`, and feeds the calibrated `(x_css, y_css)` into the live Playwright CDP `LocatorResolver` and two-gate verification loop.

## 2. Key Architectural Deliverables

### 2.1 Bounded Subprocess Supervisor (`replayfix_core::process`)
- `run_bounded(program, args, stdin_bytes, timeout, max_stdout_bytes)` spawns external binaries (`ffmpeg`, `ffprobe`) with background reader threads for `stdout` (capped at `max_stdout_bytes`) and `stderr` (bounded tail ring buffer), `mpsc::Receiver::recv_timeout` wall-clock deadlines, and automatic process-tree termination via `Platform::terminate_process_tree(pid)` on timeout or output overflow.

### 2.2 Video Prober, Geometric Calibration & Cursor-Bounded ROI Differencer (`replayfix_core::video`)
- `VideoPreprocessor`: Validates paths via `assert_safe_path`, probes container streams via `ffprobe`, extracts bounded grayscale frames for ROI analysis, writes PNG keyframes (`MAX_KEYFRAMES = 10`), and extracts 24 kHz mono 16-bit PCM WAV audio (`-vn -acodec pcm_s16le -ar 24000 -ac 1`).
- `GeometricCalibration`: Integer-math transformation from video pixel coordinates to CSS logical pixel coordinates across resolution scaling, letterbox/pillarbox padding, and DPR (`dpr_milli`).
- `RoiDiffer`: Evaluates $120 \times 120\text{px}$ cursor-bounded ROI $L_1$ frame differences and fails closed (`AMBIGUOUS_GROUNDING`, exit code `22`) when variance is below the noise floor $\tau$ or two competing regions tie within `< 2_500` bps ($|\Delta S| < 0.25$).

### 2.3 Meta Multimodal Perception Engine (`replayfix_core::perception`)
- **Meta Superpower #1 (`sam-3.1` — `SamSegmenter`)**: Parses `<|box;x1=...;y1=...;x2=...;y2=...|><|mask;...|>` wire tokens, computes the exact contour centroid $\left(\frac{x_1+x_2}{2}, \frac{y_1+y_2}{2}\right)$, enforces the `< 2_500` bps fail-closed ambiguity guard, and maps the centroid to CSS logical pixels.
- **Meta Superpower #2 (`muse-voice-transcribe-1.0` — `AsrTranscriber`)**: Enforces the Zero-Audio Rule (blocking `muse-spark-1.3` with `CoreError::SecurityViolation`), validates `PCM_24KHZ` / `ENDPOINTING` / `DELTA` / `emit_audio_progress: true`, and aligns spoken narration using cumulative `audioProcessedMs`.
- **Receipt Schema `"0.5"`**: `AuditReceipt` now includes `video_telemetry: Option<VideoTelemetry>` serialized in float-free RFC 8785 canonical JSON.
