## Overview

**ReplayFix v2.0.0** is the **Sovereign Enterprise Final MMP Release**, uniting all five enterprise architectural pillars—**Production APM & OpenTelemetry Session Replay Ingestion (`replayfix ingest`)**, **Distributed Work-Stealing Swarm Orchestration (`replayfix swarm`)**, **Real-Time Live Streaming Dashboard (`replayfix dashboard`)**, **Cross-Browser & Multi-Device Inoculation Matrix (`replayfix inoculate --matrix`)**, and **RFC 6962 Transparency Ledger & Enterprise Multi-Party Attestation (`replayfix notary` / `replayfix verify`)**—with 100% audit convergence across the entire workspace.

---

## Key Highlights

1. **Pillar 1 — Production APM, OpenTelemetry Span Alignment, SourceMap v3 & Secret Scrubbing (`replayfix ingest`)**:
   - Temporal correlation of RRWeb user click/input/scroll events with OpenTelemetry (`OtelSpan`) distributed trace spans (`OtelIngestion::align_with_rrweb`).
   - Source Map v3 (`SourceMapResolver`) stack frame resolution mapping minified bundle frames back to path-validated TypeScript/JavaScript source files (`TaskManifest::assert_safe_path`).
   - Automatic ANSI escape stripping and credential scrubbing (`redact_github_secrets` + token prefix redaction for `ghp_`, `github_pat_`, `sk-`, `glpat-`) across all ingested telemetry.
2. **Pillar 2 — High-Concurrency Distributed Triage Swarm (`replayfix swarm --workers <N> --tasks ...`)**:
   - Multi-worker work-stealing job coordinator supporting both `--tasks <task1.json> <task2.json>...` and `--bugs <RF-01,RF-02>`, isolated `ScratchSandbox` per worker ($\Delta	ext{repo}=0$), dynamic `:0` ports, shared `RatePool` & `CircuitBreaker`, live `DashboardBroadcaster` streaming, and automatic `TransparencyLog` notarization (`--notary-log`).
3. **Pillar 3 — Real-Time Live Streaming Dashboard (`replayfix dashboard --port <port> --open`)**:
   - Zero-dependency embedded HTTP, RFC 6455 WebSocket (`/ws/screencast/:task_id`), and SSE (`/events/reasoning/:task_id`) server with `/api/status`, `/api/tasks`, `/api/notary`, and `/api/matrix` endpoints and live DOM `ariaSnapshot` diff broadcasting.
4. **Pillar 4 — Cross-Browser & Multi-Device Inoculation Matrix (`replayfix inoculate --matrix`)**:
   - Synthesizes permanent Playwright regression test matrices across `chromium`, `firefox`, and `webkit` and responsive viewport presets (`mobile-portrait`, `mobile-pixel7`, `tablet`, `desktop`) with letterbox coordinate calibration (`calibrate_viewport_with_letterbox`) and matrix parity verification (`verify_matrix_parity`).
5. **Pillar 5 — RFC 6962 Transparency Log, 7-Leaf Canonical Receipts & Enterprise Multi-Party Attestation v2.0 (`replayfix notary` & `replayfix verify`)**:
   - Append-only `transparency_log.json` with RFC 6962 consistency proofs (`verify_consistency_proof`).
   - `MultiPartyAttestation` v2.0 (`Developer` + `Harness` + `CiJudge` Ed25519 quorum signatures) in `replayfix-core::crypto` and visual inspection panel in `proof_viewer.html`.
   - Canonical 7-leaf disaggregated artifact writer (`write_canonical_7leaf_artifacts`) and `replayfix verify --receipt <path> --public-key <key>` CLI alias.
