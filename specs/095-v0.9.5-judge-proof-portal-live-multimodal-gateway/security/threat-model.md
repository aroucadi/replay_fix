# Threat Model: Spec 095 — Offline Judge Proof Portal & Live Multimodal Gateway

| Threat ID | Asset | Attacker Capability | Trust Boundary | Attack Path | Preventive Control | Detection Mechanism | Negative Test | Residual Risk |
|---|---|---|---|---|---|---|---|---|
| **TM-095-01** | Browser DOM (`proof_viewer.html`) | Crafts malicious `audit_receipt.json` containing `<script>alert(1)</script>` or `<svg onload=...>` in `task_id`, `file_name`, or diff lines | Untrusted File Import $ightarrow$ Browser DOM | XSS / HTML / SVG script execution when judge inspects receipt | Strict CSP (`default-src 'none'`), zero `innerHTML` on untrusted fields, exclusive `textContent` / safe DOM node creation | Automated AST/source scan of `proof_viewer.html` + hostile payload injection test | `test_portal_xss_and_hostile_input_defense` | Low |
| **TM-095-02** | Browser Memory / CPU | Drops 500 MB JSON or 100-level nested object or `__proto__` pollution payload | Untrusted File Import $ightarrow$ Parser | Denial of service or prototype pollution in browser tab | 50 MB size gate before `FileReader`, max depth $\le 32$, safe `JSON.parse` reviver stripping `__proto__`/`constructor`/`prototype` | Explicit error banner `MALFORMED RECEIPT: ...` | `test_portal_prototype_pollution_and_size_bounds` | Low |
| **TM-095-03** | Verification Verdict Badge | Edits `status: "VERIFIED_REPAIRED"` while tampering with a diff or leaf hash | Receipt JSON $ightarrow$ Portal Verifier | Forged green `VERIFIED GENUINE` badge on tampered evidence | Portal never trusts `status` field; recomputes RFC 8785 JCS, RFC 6962 Merkle root, and Ed25519 signature | Status transitions to `INTEGRITY CHECK FAILED` in red | `test_portal_detects_tampered_merkle_leaf_and_signature` | Negligible |
| **TM-095-04** | Signer Trust Store | Signs tampered receipt with attacker-generated Ed25519 keypair | Attestation $ightarrow$ Trust Policy | Judge mistakes valid attacker signature for trusted harness key | Explicit separation between `VERIFIED GENUINE` (pinned key match) and `SIGNATURE VALID — SIGNER UNTRUSTED` | Warning badge + explicit key fingerprint comparison | `test_portal_distinguishes_untrusted_signer` | Low |
| **TM-095-05** | Offline Air-Gap Privacy | Embeds external URL (`https://evil.example/pixel.png`) in receipt fields | Portal Renderer $ightarrow$ Network | Automatic external fetch leaks judge IP or receipt contents | CSP `connect-src 'none'; img-src data: blob:;` + zero `fetch()`/`XMLHttpRequest` calls in portal | Static source audit asserting zero network primitives | `test_portal_zero_external_network_dependencies` | Negligible |
| **TM-095-06** | Cloud Gateway Quotas & Billing | Triggers text-only repair with audio payload attached | Repair Engine $ightarrow$ Cloud Gateway | Accidental audio token billing on `muse-spark-1.3` / `muse-wonder-1.0` | Zero-Audio Rule check in `GatewayClient::send` before dispatch | `CoreError::SecurityViolation("ZERO_AUDIO_RULE_VIOLATION")` | `test_gateway_zero_audio_rule_enforced` | Negligible |
| **TM-095-07** | Provider Availability | Upstream endpoint returns HTTP 429 or 503 flood | Cloud Gateway $ightarrow$ Meta API | Retry storm or hung process | Token-bucket `RatePool` + 3-state `CircuitBreaker` + bounded retries + `BasetenFallback` | Circuit transitions `Closed -> Open -> HalfOpen` | `test_gateway_circuit_breaker_and_fallback` | Low |
| **TM-095-08** | API Credentials | Logs or serializes `GatewayClient` or error messages | Process Env $ightarrow$ Logs / Receipts | Leak of `META_API_KEY` or `BASETEN_API_KEY` | Custom `Debug` redaction + leak-proof error strings + zero key fields in receipts | Assertion that raw token string never appears in debug/error output | `test_gateway_redacts_api_credentials` | Negligible |
